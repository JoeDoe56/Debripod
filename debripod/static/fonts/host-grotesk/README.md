# Host Grotesk

`HostGrotesk-latin-wght-300-800.woff2` is the Latin subset of the Host Grotesk
variable font, covering weights 300 through 800. It is bundled for the MENU
label's native 800 (ExtraBold) face.

Source: https://cdn.jsdelivr.net/npm/@fontsource-variable/host-grotesk@5.2.5/files/host-grotesk-latin-wght-normal.woff2

The font is authored by the Host Grotesk Project Authors and distributed under
the SIL Open Font License 1.1. The complete license text is in `OFL.txt`.
The upstream project is https://github.com/Element-Type/HostGrotesk.
